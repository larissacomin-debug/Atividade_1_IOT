# Atividade_1_IOT

Discente: Larissa Comin

Docente: Amanda Paul Dull

Nessa atividade usamos um botão como entrada para controlar um LED. Ao clicar no botão, o Arduino altera o estado do LED (true - liga; false - desliga).

- O Arduino lê o estado do botão pelo pino 7.
- Controla o led pelo pino 10.

*Componentes*

1	Placa Arduino UNO

1	Cabo USB

1	Protoboard

1	Resistor de 200 Ω ou 220 Ω

1	Resistor de 10 kΩ

1	Botão tipo botão de pressão

1	LED vermelho 

Fios de jumper macho-macho
